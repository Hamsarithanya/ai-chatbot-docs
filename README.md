# AI Chatbot Project Documentation

## Introduction
The AI Chatbot is an intelligent assistant built to chat with users, answer questions, and provide helpful guidance in real-time.

## Features
- Smart text-based conversation
- Fast and automated replies
- Clean, modern layout
- Friendly user experience

## Technologies Used
- HTML
- CSS
- JavaScript
- Markdown

## Installation
1. Download this project folder to your computer.
2. Open the folder using your code editor.
3. Launch the index.html file in your internet browser.

## Usage
1. Open the chat screen.
2. Type your message in the chat box at the bottom.
3. Click the Send button or press Enter to talk to the AI.
